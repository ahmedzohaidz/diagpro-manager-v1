# DiagPro Manager V1

نظام عربي باتجاه RTL لإدارة حجوزات ورش صيانة السيارات.

## المرحلة الحالية
تأسيس واجهة Next.js وصفحة طلب موعد أولية. **نموذج الحجز تجريبي ولا يحفظ أو يرسل بيانات العملاء بعد.**

## التشغيل المحلي
```bash
npm install
npm run dev
```

## فحوصات الجودة
```bash
npm run type-check
npm run lint
npm test
npm run build
```

## الإعدادات القادمة
- إعداد Supabase ومخطط قاعدة البيانات وسياسات RLS.
- API للتحقق من بيانات الحجز وحفظها.
- لوحة مشرف الحجوزات.
- تحويل الحجز إلى أمر عمل.
- قوالب رسائل جاهزة لواتساب.

لا تضع مفاتيح Supabase السرية في ملفات عامة أو في المستودع.
