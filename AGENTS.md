# DiagPro Manager V1 — Codex Instructions

## Project Goal
Build DiagPro Manager V1 — Cash Flow Version for an Arabic RTL auto workshop management system.

## Current Scope
Focus only on the online booking flow first:
1. Project scaffold
2. /book page
3. Admin bookings dashboard
4. Convert booking to work order
5. WhatsApp-ready messages
6. Booking Customer Supervisor Agent later

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- Arabic RTL layout
- Brand colors: #FFD100 and black

## Rules
- Do not build the full system at once.
- Do not add AI agents unless explicitly requested.
- Do not add invoices yet unless explicitly requested.
- Do not add authentication yet unless explicitly requested.
- Do not add advanced inventory or diagnostics yet.
- Keep every phase small and testable.
- Use Arabic UI text.
- Use RTL direction everywhere.
- Keep code clean and organized.
- After every task, report:
  - Files changed
  - Commands run
  - How to test
  - What remains for the next phase

## UI Identity
Use a clean modern Arabic interface.
Primary color: #FFD100.
Use black accents.
Avoid dark full-page backgrounds for V1.

## Success Standard
The app must run locally after each phase without errors.
